# NeuroScope Phase 2A.2 — anatomical assets

This milestone prepares cortical surface assets only. The homepage and existing Three.js scene still use the procedural sculpture. No neural pathways or particles are generated by this pipeline.

## Reproduce

Run from the repository root. The tested environment is CPython 3.12.14 on macOS arm64; the pinned dependencies target Python 3.12 with compatible binary wheels. Use a separate environment from the frontend.

```sh
python3.12 -m venv .venv-anatomy
.venv-anatomy/bin/python -m pip install -r scripts/requirements-anatomy.txt
.venv-anatomy/bin/python -B scripts/prepare-anatomy.py
.venv-anatomy/bin/python -B -m unittest discover -s scripts -p test_anatomy.py -v
.venv-anatomy/bin/python -B scripts/preview-anatomy.py
```

The requirements file pins the entire installed Python dependency set. PyMeshLab performs topology-preserving decimation, trimesh handles input/export and geometry checks, NumPy/SciPy/Rtree support numeric validation, and Matplotlib renders previews. All processing runs offline after installation. No frontend package changes are required.

Independent format validation uses the official Khronos validator in an ignored, isolated tooling directory:

```sh
npm install --prefix .cache/anatomy-validator --ignore-scripts --no-audit --no-fund --cache .cache/npm gltf-validator@2.0.0-dev.3.10
node scripts/validate-anatomy.cjs
```

The Python script accepts `--source` and `--output`; defaults are `work/anatomy/pial_Full_obj` and `public/models`. It rejects inputs whose hashes differ from the verified publisher files. Both profiles must pass all Python checks before either is written. Existing source OBJ files are never modified. Re-running replaces the generated GLBs and manifest. The Node validator exits unsuccessfully on any warning or error.

For repeatability, generate into a second directory and compare SHA-256 hashes. Byte identity is checked on the tested platform; cross-platform byte identity is not promised. The manifest excludes timestamps but records Python and geometry-library versions.

## Coordinates and geometry policy

The source uses FreeSurfer surface RAS axes: X right, Y anterior, Z superior ([coordinate reference](https://nmr.mgh.harvard.edu/mne/0.14/manual/source_localization/forward.html)). A single combined bounding-box center and uniform scale are used for both hemispheres. The anterior-posterior length is normalized to **3.25 scene units**. These are display units, not physical metres. The manifest records the complete transform and scale, so source distances remain recoverable.

The rotation maps `(x, y, z)` to `(x, z, -y)`: **+X right, +Y superior, -Z anterior**. Its determinant is +1: no reflection, hemisphere exchange, independent centering, or aspect distortion. Left/right vertex asymmetry and the original relative placement are retained.

MeshLab's quadric edge-collapse decimator uses topology, normal, and boundary preservation, a 0.3 quality threshold, optimal vertex placement, and automatic cleanup. No smoothing filter is applied. Each quality is generated directly from the original mesh, not from the other quality. Normals are recomputed after decimation. See [MeshLab's filter documentation](https://pymeshlab.readthedocs.io/en/latest/filter_list.html#meshing-decimation-quadric-edge-collapse).

Processing software: Alessandro Muntoni and Paolo Cignoni, *PyMeshLab* (2021), [doi:10.5281/zenodo.4438750](https://doi.org/10.5281/zenodo.4438750). The installed processing library has its own GPL-3.0 license and is not shipped to browsers.

The GLBs contain two named meshes/nodes, `cortex_left` and `cortex_right`, with baked coordinates and identity node transforms. Each has indexed triangles, float32 positions, unit normals, and a neutral opaque PBR material. There are no textures, external buffers, decoder extensions, or animation dependencies. Source/license and adaptation metadata are embedded in the GLB.

Each hemisphere contributes half the triangle count. Combined dimensions are approximately **2.65 × 2.28 × 3.25** scene units (right-left × superior-inferior × anterior-posterior). The worst directional sampled 99th-percentile surface error is **0.105 mm full / 0.325 mm compact**; sampled maxima are **0.352 mm / 1.229 mm**. Surface-area change remains below **1.22% / 3.31%**, and volume change below **0.012% / 0.168%**. Both preserve the original folds and proportions within these measured limits.

Both assets passed the independent Khronos validator with **zero errors and zero warnings**. It reports six optional `BUFFER_VIEW_TARGET_MISSING` hints per file; buffer targets are inferred from their accessor use and are not required for glTF validity. No decoding extension is needed.

All nine regression tests passed. A second complete build produced byte-identical GLBs and manifest. Visual inspection of the three-view comparison confirms retained cerebral silhouette, longitudinal fissure, and major cortical folds. The compact mesh is more faceted in this flat-face-shaded inspection preview; both GLBs contain smooth vertex normals for later rendering. Frontend source files, package manifests, and source OBJ bytes remain unchanged.

## Validation

`public/models/manifest.json` is the machine-readable record of input/output hashes, transforms, bounding boxes, triangle and vertex counts, bytes, and per-hemisphere checks:

- Nonempty, finite positions; valid indices; referenced vertices; no duplicate or degenerate faces.
- One connected, closed surface per hemisphere, consistent outward winding, positive volume, Euler characteristic 2, finite unit normals.
- Preserved left/right placement, common scale, and sensible combined dimensions.
- Deterministic area-weighted point-to-triangle distances: 6,000 samples in each direction per hemisphere. This is a sampled estimate, not an exhaustive Hausdorff bound.
- Full profile limits: 99th-percentile deviation ≤0.35 mm, sampled maximum ≤1 mm, surface-area error ≤3%, volume error ≤1%.
- Compact limits: 99th-percentile deviation ≤0.8 mm, sampled maximum ≤2 mm, surface-area error ≤8%, volume error ≤3%.
- Each bounding-box endpoint stays within 1 mm of the normalized original when converted back to source units.
- Both GLBs are reloaded and checked for matching topology, positions, normals, hemisphere names, and transforms.
- Delivery budgets: full ≤5 MB and compact ≤1.6 MB, uncompressed. Gzip size is informational; actual transfer size depends on server configuration.

`public/models/gltf-validation.json` records independent Khronos glTF 2.0 conformance results and matching file hashes. `work/anatomy-preview/comparison.png` compares the original and both parsed GLBs from identical lateral, superior, and three-quarter views. Preview output is reproducible and excluded from Git.

No exhaustive self-intersection analysis, clinical validation, browser rendering, GPU performance, or frame-rate claim is made in this asset milestone. The assets represent the cerebral cortex; cerebellum and brainstem are absent from the supplied input.
